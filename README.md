Для пользователей приложения
Данное приложение выполнено с использованием сервиса GREEN-API, выполненное на React, позволяющее обмениваться сообщениями посредством кастомного клиента

для локального запуска проекта необходимо выполнить установку зависимостей
на node 22, выполнив команду
npm install

затем запустить проект командой
npm run dev

далее нужно ввести данные GREEN-API инстанса в форме логина, далее останется только заполнить поле с номером телефона собеседника
